​Book Library Website
​A modern, responsive web-based library interface designed to provide users with an engaging and seamless experience for exploring books and multimedia resources. Built using HTML5, CSS3, and Bootstrap, this application features a clean, intuitive layout with smooth user interactions.
​Key Features:
​Interactive Navigation: Categorized dropdown menus for browsing both books and video content across various subjects (Arabic, Mathematics, Studies, and Sciences).
​Search Functionality: An integrated search bar allowing users to quickly look up titles.
​Featured Sections: Dedicated showcases for "Up Coming Books" and "Most Watched Books" using dynamic card layouts.
​Visual Appeal: Enhanced with custom fonts (Google Fonts), FontAwesome icons, and interactive visual elements.
​Smooth Animations: Includes scroll-triggered fade-in animations to improve overall user experience and interactivity.
​User Authentication Links: Dedicated UI components for User Sign Up and Login workflows.
​Tech Stack:
​Frontend: HTML5, CSS3, Bootstrap 5
​Icons & Fonts: FontAwesome, Google Fonts
​Scripts: JavaScript (Scroll Animations & UI Interactivity)
